# 인사이트 구현의 추가 의존성

기존 textarea 기반 관리자에 구조화 블록·DB 저장·이력 비교를 확장했습니다. 다른 CMS나 유료 편집기를 추가하지 않았습니다. 번역·수집한 문서 자체의 이용 조건은 패키지 라이선스와 별도로 운영자가 확인합니다.

| 패키지 | 이번 설치 버전 | 용도 | 라이선스 |
| --- | --- | --- | --- |
| @anthropic-ai/sdk | 0.132.1 | 모델 확인·구조화 작성 API | MIT |
| @mozilla/readability | 0.6.0 | 실행 없는 문서 본문 추출 | Apache-2.0 |
| dompurify | 3.4.16 | 추출 HTML 정리 | MPL-2.0 또는 Apache-2.0 |
| ipaddr.js | 2.5.0 | IP 주소 범위 검사 | MIT |
| jsdom | 30.1.2 | 별도 worker 안의 DOM 파싱 | MIT |
| zod | 4.6.5 | 글 블록·작성 응답 검증 | MIT |

버전·라이선스는 설치된 package.json에서 확인했습니다. lockfile을 함께 보관하고 배포 패키지에 원래 라이선스 파일을 유지하세요. jsdom 30.1.2의 Node 요구 조건은 `^22.22.2 || ^24.15.0 || >=26.0.0`이며 이번 실행·컨테이너 기준은 Node 24입니다. 이들 파서는 Node 작업 프로세스에서만 사용하며 사이트 브라우저나 Sites worker에 넣지 않습니다.
